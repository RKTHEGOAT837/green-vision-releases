Windows 10 or 11 · 64-bit

Take this one, not the public download

The public page offers the open build. Windows treats the two as different applications, so installing that one would leave you with a second copy alongside this one rather than updating it. If you have already done that, uninstall Green Vision and keep Green Vision Managed.

Installing it

  1. Download the file above.
  2. Windows will warn you: “Windows protected your PC”. That is expected — the installer is not code-signed. Click More info, then Run anyway.
  3. Run it. Your saved projects and your sign-in are kept.

Check the file if you want to

Get-FileHash .\GreenVision-Managed-x64.exe

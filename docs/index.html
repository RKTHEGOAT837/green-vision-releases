Download for Windows
Windows 10 or 11  ·  64-bit

Windows will show a warning. This is expected.

The installer is not code-signed — a certificate costs a few hundred dollars a year, and this is an early build. Windows SmartScreen flags any unsigned installer, however harmless. To continue:

  1. Click More info on the blue "Windows protected your PC" dialog
  2. Click Run anyway

If you would rather verify the file first, its SHA-256 should be exactly:

Check it in PowerShell with Get-FileHash .\GreenVision-1.0.0-x64.exe

What you get

  • Everything is included. No Python, no setup, no API keys. The analysis engine and a 2.6-million-feature map index install with the app.
  • It works offline. Map reads are answered from your own machine rather than a public server, so the Traffic tab and the area census load in under a second and never hit a rate limit.
  • Five cities baked in — Ahmedabad, Bengaluru, Chennai, Delhi and Mumbai — and any point in India can be analysed on the map.
  • Signing in is optional. The app is fully usable without an account; an account adds saved projects, assistant memory, search history and the shared Library.

A desktop shortcut is created for you. Opening it starts the engine automatically — nothing else to run. Installing a newer version replaces this one; your projects and your sign-in are kept.

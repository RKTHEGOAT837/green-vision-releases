# Green Vision - Windows downloads

Tree-planting prioritisation for Indian cities: air quality, canopy loss,
traffic bottlenecks, soil and cost, on one map.

**[Download the latest version](../../releases/latest)**

This repository exists only to host the installer. GitHub does not meter
bandwidth on release assets, so downloads here are free and unlimited - which
is why the file lives here rather than on the web host.

The application source is not published here.

## Installing

The installer is not code-signed, so Windows SmartScreen shows
*Windows protected your PC*. Click **More info**, then **Run anyway**.
Each release lists the file SHA-256 so you can verify it first.

Nothing else needs installing. The analysis engine and a 2.6-million-feature
OpenStreetMap index ship inside the download, so the app works offline and map
reads are answered from your own machine.
